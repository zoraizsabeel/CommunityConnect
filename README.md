# CommunityConnect

A professional connection tool organized around shared communities, participation, and personal contact preferences.

## Project status

Concept and validation planning. No application has been implemented.

## Planning

- [Concept and development plan](docs/concept-and-development-plan.md)
- [Original editable planning Page](https://chatgpt.com/space/page_461f150307a88191a0fd262efaeacbfe)

The plan covers community membership, visible activity, personal interaction thresholds, QR connections, the community feed, validation, business questions, and a learning-led software development process.

## Working approach

The project owner leads learning and implementation. AI assistance supports planning, assigned research, explanation, review, and explicitly delegated implementation.

Project messages and updates are recorded in GitHub Issues. The repository document is a snapshot of the planning Page; they are not automatically synchronized.
